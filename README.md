# 🪨📄✂️ Rock Paper Scissors Game

A clean, interactive, and responsive **Rock Paper Scissors** web application built with vanilla HTML, CSS, and JavaScript. Play against the computer, track scores in real-time, and reset whenever you want!

---

## ✨ Features

* **Interactive Gameplay:** Simple move selection using interactive buttons.
* **Real-time Scoreboard:** Live tracking of player and computer scores.
* **Dynamic Results Display:** Immediate feedback showing user choice, computer choice, and game status.
* **Restart Functionality:** Reset scores and move states back to zero at any point.
* **Responsive UI:** Modern, clean card UI with a smooth gradient background designed for desktop and mobile views.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic structure and interface components.
* **CSS3:** Modern flexbox layout, custom styling, and gradient aesthetics.
* **JavaScript (ES6):** Game logic, state management, and DOM manipulation.
